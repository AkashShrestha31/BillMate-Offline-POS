# Changelog

## 1.0.0 — 2026-11-25

First public source release of BillMate, an offline POS for restaurants and shops. App version **1.0.0** (build **27**).

- Offline SQLite books for sales, purchases, parties, stock, payroll, and day-end
- Restaurant floor plan, table orders, and KOT
- Retail / shop checkout
- Android and iOS
- Flutter 3.41.9, Dart 3.11.5

Signing keys and Firebase project files are not in this tag. Add your own before a store build.
